# Michael Thompson Personal Portfolio

## Project Description
This personal portfolio website was created for the ISDS 4125 Individual Vibe Coding Exercise. It presents my professional profile, skills, work experience, resume, and a featured internal audit project. The website was developed locally using Google Antigravity, tracked with Git and GitHub, and published using GitHub Pages.

## Live Website
https://mike-t04.github.io/michael-thompson-website/

## Reflection
One thing I did not understand at first was why some styling should be moved out of the individual HTML pages and into one shared styles.css file. After asking the Antigravity agent about it, I learned that all three pages can use the same stylesheet. This means I can change things like fonts, colors, and spacing in one place instead of changing each page separately, which helps keep the website consistent and easier to manage.
